Nabby vs youtubedl-material

A paste-and-go tool compared to a Plex-adjacent library for your downloads.

The short version

youtubedl-material (ytdl-material) is a mature, feature-rich self-hosted media manager built around yt-dlp. It supports user accounts, subscriptions, playlists, and a long-running library. Nabby is a minimal single-user web UI with no persistence. Different products for different jobs.

Choose youtubedl-material if…

  • You're building a permanent personal media library (YouTube-channel subscriptions, podcast archives, Twitch VOD collections).
  • You want multi-user access with per-user folders and playlists.
  • You want auto-download on new uploads from subscribed channels.
  • You enjoy the Plex-adjacent dashboard experience.

Choose Nabby if…

  • You don't want a library — you want a web form that calls yt-dlp.
  • You want files auto-deleted after use.
  • You run a lot of small VPSes and want each service to use ~60 MB RAM.
  • You don't want an account system, user management, or a database.

Honest notes

youtubedl-material is a bigger product solving a bigger problem. If you want to archive thousands of videos across accounts and friends, use it. If you want a bookmark-style quick grab for one-off downloads, Nabby is simpler.
